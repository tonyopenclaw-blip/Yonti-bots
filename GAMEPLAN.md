## 2. SETTLEMENT MECHANICS DEEP DIVE

### The Question
> "Is the 60-second average price at close >= 60-second average price at open?"

### How It Works
- **floor_strike** (open reference) = 60-second average price at window OPEN
- **ceil_strike** (close reference) = 60-second average price at window CLOSE
- YES wins if: `close_avg >= open_avg` (price stable or rising)
- NO wins if: `close_avg < open_avg` (price falling)

### Critical: The floor_strike IS the open reference
The floor is NOT a support level in the traditional sense. It's the **baseline average** from the open 60 seconds.

### The Price vs Floor Comparison (Our Missing Edge)

**The fundamental rule:**
```
IF Coinbase_price_at_open > floor_strike → YES is ahead (baseline is already beat)
IF Coinbase_price_at_open < floor_strike → NO is ahead (must work harder to catch up)
```

**The problem**: We don't currently have Coinbase price feed integration in our bot. The SUPERBOT needs to:

The orderbook tells you what the market thinks. The floor_strike comparison tells you whether the current price is consistent with that expectation.

## 5. THE KELLY SIZING FIX

### The Problem
```
Standard Kelly: f* = (bp - q) / b
Where: p = win prob, b = reward ratio, q = 1-p

With W = 0% (no wins), this breaks:
f* = (0.85 × 0 - 1) / 0.85 = -1.18 → invalid
```

### The Fix: Conservative Kelly for No Track Record

**Option A: Floor Kelly (Recommended)**
```
If W < 30% or N < 5 trades:
    Use Conservative Kelly = MIN(6% of bankroll, $0.50)
    (Cap at 6% regardless of formula)
```
**Option B: Bayesian-Adjusted Kelly**
```
Use prior: p = 57% (break-even rate assumption)
Then: f* = (0.85 × 0.57 - 0.43) / 0.85
     = (0.4845 - 0.43) / 0.85 = 0.064 = 6.4%
     → Half Kelly = 3.2% of bankroll
```
**Option C: Fixed Fractional (Simplest)**
```
With $7.94 bankroll and no track record:
    Max bet = $0.50 (6.3% of bankroll)
    Ideal bet = $0.25 (3.1% of bankroll)
```
