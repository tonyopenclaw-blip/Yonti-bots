## Superbot Troubleshooting Session

### Problems Found & Fixed

1. **Scanner file stale** — bot reading `/tmp/kalshi_scanner_live_markets.json` which had old markets (closed 2+ hours ago). Fixed: modified `CoinTrader.get_scanner_markets()` to use `self.api.get_open_markets()` directly instead of relying on scanner file.

2. **kalshi_api.py rebuilt with bugs** — Original used kalshi_py SDK. My replacement had auth signature bug (`get_auth_headers` returns dict, not tuple). Also missing `series_ticker` in Market objects. Fixed.

3. **Market status filter wrong** — Code checked `status="open"` but Kalshi API returns `status="active"` for active markets. Changed filter to accept both.

4. **CoinTrader.cash not synced** — `CoinTrader.self.cash` was initialized to `PAPER_BALANCE/8 = $1.27` but never updated from Superbot's cash ($10.18). Fixed in `_distribute_cash_to_traders()`: now sets `trader.cash = self.cash` in addition to `trader.strategy_engine.update_cash()`.

5. **scanner.market_exists check blocking** — `StrategyEngine.evaluate_market()` at line 388 had `if not self.scanner.market_exists(ticker): return None, 0` which rejected fresh markets because scanner file was stale. Removed this check.

6. **get_open_markets fallback wrong** — In `CoinTrader.get_markets()`, fallback to API was calling `self.api.get_markets()` (returns ALL markets) instead of `self.api.get_open_markets()`. Fixed.
