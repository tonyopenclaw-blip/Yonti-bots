- Place $1 YES + $1 NO limit orders at ≤$0.15 per contract on every coin in cluster

- If either side can't get ≤$0.15 → skip entirely, normal MACRO_FADE continues

### Implementation
- Added `_place_open_orders()` method to superbot.py
- Added `ORDER_TYPE_LIMIT = "limit"` to kalshi_api.py
- Added call in trading loop right after CANDLE SIGNALS block (~line 1447)
- SB restarted with new code: PID 1626641 → 1626690

### Parameters
- Max price: $0.15/contract
- $1 per side ($2 total per coin)
- Must have 5+ coin cluster
- Market must be < 60 seconds old
- Fresh signal only (age < 60s)
- 30s wait for fills, then cancel

### Thesis
Markets often open with both sides cheap after a pump/dump (market makers haven't repriced yet). We exploit the ~15 second window before spreads widen. Cost: $2/coin × 8 = $16 total. Payout if reversal hits: ~$6/coin × 8 = ~$48. 3:1 reward/risk on a high-probability fade.
